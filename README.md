# Unity Quiz Game

A quiz game project built with **Unity**, using **UI Toolkit** for both **runtime gameplay UI** and **custom editor tools**.  
The project focuses on managing quiz content (questions, categories, and settings) through editor tooling and using that data during gameplay.

## Features

- **Quiz Gameplay**
  - Question-based quiz system with 
  - Supports single choice, multiple choice, and true/false questions
  - Category-based questions
  - Configurable quiz settings
  - Runtime UI created with UI Toolkit

- **Custom Editor Tools**
  - Editor interfaces built with UI Toolkit
  - Create and manage:
    - Quiz questions
    - Question categories
    - Quiz settings
  - Improves workflow for authoring quiz content

- **Data-Driven Design**
  - Quiz content separated from gameplay logic
  - Easy to expand with new questions or categories
